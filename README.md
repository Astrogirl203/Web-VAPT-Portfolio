# Web-VAPT-Portfolio
Websites that I've done PT during my internship with Redlline Shield. All of this are done manually.  

This repository contains write-ups and reports for web application penetration testing (VAPT) performed manually during my security internship at **Redline Shield**.

⚠️ **Disclaimer:** All testing was authorized under strict non-disclosure/scope agreements. Sensitive hostnames, IP addresses, credentials, and client-side.

## 🛠️ Testing Methodology & Tools
- **Frameworks:** OWASP Web Security Testing Guide (WSTG v4.2)
- **Tools:** Burp Suite Professional/Community, Nmap, FFUF, SQLmap, DevTools
- **Focus Areas:** Authentication Bypass, Authorization Controls (IDOR), SQLi, XSS, Business Logic Flaws
