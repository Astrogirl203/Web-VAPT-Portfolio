A manual web application penetration test was conducted on wemoney.com.au to identify 
security vulnerabilities against a defined set of target security issues. The scope was strictly 
limited to the primary wemoney domain. The assessment focused on manual interception, 
analysis, and manipulation of HTTP requests using Burp Suite Professional. 

Vulnerablities tested:
1) Rate Limiting
2) Cross-Origin Resource Sharing (CORS) 
3) Stored XSS via SVG Upload 
4) Session Issues
5) Clickjacking Protections
6) Clickable Link Injection in Email
7) Race Conditions
