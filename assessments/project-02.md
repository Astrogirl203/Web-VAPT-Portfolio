A manual web penetration test conducted on https://target.com.au, focusing on Input Validation 
(SQL Injection, Cross-Site Scripting) and Access Controls. 
Scope: Web application search functionality, authentication endpoints, and API cart routes. 
During the testing no critical vulnerablities were found. The target's firewall by Akamai EdgeSuite was
successfully blocking all inetrcepting packets as well as XSS scripts and SQLI queries, resulting in
an endless loop on getting "Access Denied" message.

Vulnerablities Tested :
1) SQL Injection (UNION-based)
2) Cross-Site Scripting (XSS)
3) Authentication Probing
4) API Header Tampering
