A hybrid penetration test (i.e. Manual and Automatic) was conducted against https://titleonecorp.com/ to 
evaluate authentication mechanisms, input handling robustness, session management controls, 
and security hardening configurations. Through a combination of manual testing methodologies 
and intercepting proxy analysis using Burp Suite and OWASP ZAP, several security observations 
and configuration gaps were identified. 

Vulnerablities Tested :
1) Username Enumeration
2) Clickjacking / Missing Frame Protection
3) Content Security Policy Header Not Set
4) Reflected Cross-Site Scripting (XSS)
