This report details the security findings identified during a *manual*, black-box penetration testing 
assessment conducted on *www.toggo.de*. The assessment focused on evaluating client-side 
security controls, header configurations, input validation mechanisms, and exposed application 
endpoints. Several findings ranging from Low to Medium severity were identified, primarily 
involving missing security headers, exposed administrative or documentation paths, and input 
handling configurations. 

Vulnerablities Tested :
1)  Authentication Risk
2)  SSL Certificate Scope Mismatch
3)  Clickjacking
4)  Missing Security Headers
5)  Information Disclosure
6)  Input Validation & XSS Assessment

Tools Used :
1) Burpsuite
2) Nmap
3) Gobuster
4) Whois, Dig, Amass
