A focused penetration test was performed against the www.way-of-elendil.fr (A web server), emphasizing 
broken object-level authorization, authentication and password-reset behavior, sensitive-data 
exposure, SQL injection, and cross-site scripting. The most consequential observations are the 
reported plaintext exposure of sensitive credentials through the sync API and the password-reset 
flow's apparent inclusion of session/token material.

Vulnerablities Tested:
1) Broken Object Level Authorization (BOLA)
2) Broken User Authentication
3) Excessive Data Exposure / Credential Leakage
4) Cross-Site Scripting (XSS)
5)  SQL Injection (SQLi)

Tools Used :
1) Nmap
2) Enum4Linux
3) Whatweb
4) whois
5) Amass
6) Burpsuite
